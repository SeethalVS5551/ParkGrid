# ParkGrid – Parking Management System

## Project Overview
ParkGrid is a web-based parking management and reservation system developed using Python, Django, MySQL, HTML, CSS, and JavaScript. It helps users find available parking spaces, reserve parking slots, manage payments, and submit complaints. The system provides separate dashboards for users, parking managers, and administrators.

## Features
- User registration and login
- Role-based access for users, parking managers, and administrators
- View available parking locations and parking slots
- Parking slot booking and reservation
- Booking history and cancellation
- Advance payment and balance payment management
- QR code-based parking entry verification
- Parking slot availability management
- Complaint submission with image upload
- Complaint tracking and response
- Admin approval and management features

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Main Modules

### 1. User Module
Allows users to register, log in, search for available parking spaces, book parking slots, view booking history, manage payments, and submit complaints.

### 2. Parking Manager Module
Allows parking managers to manage parking slots, monitor bookings, verify parking entries, manage payments, and handle user complaints.

### 3. Admin Module
Allows administrators to manage users, parking managers, and overall system activities.

## Project Objective
The main objective of ParkGrid is to simplify parking reservation and management by providing an organized platform for users and parking administrators. It helps improve parking slot utilization and makes the booking and management process more convenient.
